# Class 10 Sanskrit - Pratyay (प्रत्यय) Notes

💡 **Exam Tip:** In the CBSE Class 10 Board Exams, Pratyay questions are asked in **Multiple Choice Question (MCQ)** format. Your primary goal is not to memorize complex derivations, but to master **word recognition**—identifying the correct ending sound (शेष) of a word to determine the Pratyay.

## 1. What is a Pratyay? (परिभाषा)

A **Pratyay (Suffix)** is a syllable or set of syllables added to the **end** of a root word (Dhatu) or a noun/pronoun (Shabd) to change or modify its meaning.

**Formula:** Word/Root + Pratyay = New Word

## 2. Types of Pratyay in Class 10

Based on the CBSE syllabus, you need to study two main categories:

1. **Taddhit Pratyay (तद्धित प्रत्यय):** These are added to **words** (Nouns, Pronouns, Adjectives).
    
2. **Krit Pratyay (कृत् प्रत्यय):** These are added to **verb roots (Dhatu)**. _(Note: CBSE has recently shifted some Krit Pratyays from the Class 9 syllabus to the Class 10 syllabus)._
    

## Part A: Taddhit Pratyay (तद्धित प्रत्यय)

Added to words (Shabd Roop).

### 1. Matup Pratyay (मतुप्)

- **Meaning:** "Possessing" or "Having" (वाला / युक्त).
    
- **What remains (शेष):** **मत् (mat)** or **वत् (vat)**.
    
- **Trick:** If the original word ends with 'अ' (a) or 'आ' (aa), it becomes **वत् (vat)** [वान् in masculine]. For other vowel endings (इ, ई, उ, ऊ), it becomes **मत् (mat)** [मान् in masculine].
    

|   |   |   |   |   |
|---|---|---|---|---|
|**Word (शब्द)**|**Pratyay (प्रत्यय)**|**Masculine (पुंलिंग) - वान्/मान्**|**Feminine (स्त्रीलिंग) - वती/मती**|**Neuter (नपुंसकलिंग) - वत्/मत्**|
|बल (Bala)|मतुप् (Matup)|बलवान् (Balavan)|बलवती (Balavati)|बलवत् (Balavat)|
|बुद्धि (Buddhi)|मतुप् (Matup)|बुद्धिमान् (Buddhiman)|बुद्धिमती (Buddhimati)|बुद्धिमत् (Buddhimat)|
|शक्ति (Shakti)|मतुप् (Matup)|शक्तिमान् (Shaktiman)|शक्तिमती (Shaktimati)|शक्तिमत् (Shaktimat)|

### 2. Thak Pratyay (ठक्)

- **Meaning:** "Relating to" or "Studying".
    
- **What remains (शेष):** **इक् (ik)**.
    
- **CRITICAL RULE:** The **first vowel** of the original word elongates (Vridhi):
    
    - अ (a) ➔ आ (aa) (e.g., Dharma ➔ Dha)
        
    - इ, ई, ए (i, ii, e) ➔ ऐ (ai) (e.g., Veda ➔ Vai)
        
    - उ, ऊ, ओ (u, uu, o) ➔ औ (au) (e.g., Bhuta ➔ Bhau)
        

|   |   |   |   |
|---|---|---|---|
|**Word (शब्द)**|**Pratyay (प्रत्यय)**|**Formed Word (शब्दरूप)**|**Hindi Meaning**|
|धर्म (Dharma)|ठक् (Thak)|धार्मि**कः** (Dhaarmikah)|धर्म से संबंधित|
|दिन (Dina)|ठक् (Thak)|दैनि**कः** (Dainikah)|प्रतिदिन होने वाला|
|वेद (Veda)|ठक् (Thak)|वैदि**कः** (Vaidikah)|वेद से संबंधित|

### 3. Twa Pratyay (त्व)

- **Meaning:** Creates an Abstract Noun (भाववाचक संज्ञा) - similar to "-ness" in English.
    
- **What remains (शेष):** **त्वम् (twam)**.
    
- **Rule:** Words formed with 'Twa' are always in the **Neuter Gender (नपुंसकलिंग)**.
    

|   |   |   |   |
|---|---|---|---|
|**Word (शब्द)**|**Pratyay (प्रत्यय)**|**Formed Word (शब्दरूप)**|**English Equivalent**|
|गुरु (Guru)|त्व (Twa)|गुरु**त्वम्** (Gurutwam)|Heaviness / Greatness|
|महत् (Mahat)|त्व (Twa)|मह**त्त्वम्** (Mahattwam)|Importance|
|पशु (Pashu)|त्व (Twa)|पशु**त्वम्** (Pashutwam)|Animalness|

### 4. Tal Pratyay (तल्)

- **Meaning:** Creates an Abstract Noun (भाववाचक संज्ञा) - similar to "-ity" in English.
    
- **What remains (शेष):** **ता (taa)**.
    
- **Rule:** Words formed with 'Tal' are always in the **Feminine Gender (स्त्रीलिंग)**.
    

|   |   |   |   |
|---|---|---|---|
|**Word (शब्द)**|**Pratyay (प्रत्यय)**|**Formed Word (शब्दरूप)**|**English Equivalent**|
|जन (Jana)|तल् (Tal)|जन**ता** (Janataa)|Public / Humanity|
|मूर्ख (Murkha)|तल् (Tal)|मूर्ख**ता** (Murkhataa)|Stupidity|
|मित्र (Mitra)|तल् (Tal)|मित्र**ता** (Mitrataa)|Friendship|

## Part B: Krit Pratyay (कृत् प्रत्यय)

Added to Verb Roots (Dhatu). _(Focus on these core syllabus elements moved to Class 10)._

### 1. Shatri Pratyay (शतृ)

- **Meaning:** "While doing" (Present Continuous for Parasmaipadi verbs).
    
- **What remains (शेष):** **अत् (at)** ➔ which often looks like **अन् (an)** in masculine.
    

|   |   |   |   |   |
|---|---|---|---|---|
|**Root (धातु)**|**Pratyay**|**Masculine (-अन्)**|**Feminine (-न्ती)**|**Neuter (-अत्)**|
|पठ् (Path - read)|शतृ|पठन् (Pathan)|पठन्ती (Pathanti)|पठत् (Pathat)|
|गम्/गच्छ (Gam - go)|शतृ|गच्छन् (Gacchan)|गच्छन्ती (Gacchanti)|गच्छत् (Gacchat)|

### 2. Shanach Pratyay (शानच्)

- **Meaning:** "While doing" (Present Continuous for Atmanepadi verbs).
    
- **What remains (शेष):** **मान (maan)**.
    

|   |   |   |   |   |
|---|---|---|---|---|
|**Root (धातु)**|**Pratyay**|**Masculine (-मानः)**|**Feminine (-माना)**|**Neuter (-मानम्)**|
|सेव् (Sev - serve)|शानच्|सेवमानः (Sevamana)|सेवमाना (Sevamanaa)|सेवमानम् (Sevamanaam)|
|लभ् (Labh - get)|शानच्|लभमानः (Labhamana)|लभमाना (Labhamanaa)|लभमानम् (Labhamanaam)|

### 📌 Quick Revision Guide for MCQs (The "End-Sound" Trick)

- If word ends in **-वान् / -मान्** ➔ `Matup (मतुप्)`
    
- If word ends in **-इकः** ➔ `Thak (ठक्)`
    
- If word ends in **-त्वम्** ➔ `Twa (त्व)`
    
- If word ends in **-ता** ➔ `Tal (तल्)`
    
- If word ends in **-अन्** ➔ `Shatri (शतृ)`
    
- If word ends in **-मानः** ➔ `Shanach (शानच्)`
