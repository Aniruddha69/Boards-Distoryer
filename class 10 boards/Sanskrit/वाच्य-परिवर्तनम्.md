# Class 10 Sanskrit - Vachya (वाच्य) Notes

💡 **Exam Tip:** In CBSE Class 10, Vachya (Voice) usually comes as a 3-mark question, often in fill-in-the-blanks or MCQ format. Mastering the basic formulas and the 1st-to-3rd case subject conversions is the key to scoring full marks.

## What is Vachya (वाच्य)?

**Vachya** means "Voice" in grammar. It determines whether the verb is acting according to the Subject (Karta), the Object (Karma), or the Action itself (Bhava).

There are three types of Vachya in Sanskrit:

1. **Kartri Vachya (कर्तृवाच्य)** - Active Voice
    
2. **Karma Vachya (कर्मवाच्य)** - Passive Voice
    
3. **Bhava Vachya (भाववाच्य)** - Impersonal Voice
    

## 1. Kartri Vachya (कर्तृवाच्य) - Active Voice

In Kartri Vachya, the focus is on the **Subject (Karta)**. The verb follows the Purush (Person) and Vachan (Number) of the Subject.

- **Formula:** Subject (1st Case) + Object (2nd Case) + Verb (Follows Subject)
    
- **Karta (Subject):** Prathama Vibhakti (1st Case)
    
- **Karma (Object):** Dwitiya Vibhakti (2nd Case)
    
- **Kriya (Verb):** Follows the Karta (usually Parasmaipada endings like ति, तः, अन्ति).
    

**Examples:**

- बालकः पुस्तकं पठति। (The boy reads a book.)
    
    - _Balakah_ (1st) + _Pustakam_ (2nd) + _Pathati_ (verb matches Balakah).
        
- अहम् पत्रं लिखामि। (I write a letter.)
    
    - _Aham_ (1st) + _Patram_ (2nd) + _Likhami_ (verb matches Aham).
        

## 2. Karma Vachya (कर्मवाच्य) - Passive Voice

In Karma Vachya, the focus is on the **Object (Karma)**. The verb follows the Purush and Vachan of the Object.

- **Formula:** Subject (3rd Case) + Object (1st Case) + Verb (Follows Object)
    
- **Karta (Subject):** Tritiya Vibhakti (3rd Case)
    
- **Karma (Object):** Prathama Vibhakti (1st Case)
    
- **Kriya (Verb):** Follows the Karma (Atmanepada endings with a 'य' added to the root, e.g., यते, येते, यन्ते).
    

**Examples:**

- बालकेन पुस्तकं पठ्यते। (A book is read by the boy.)
    
    - _Balakena_ (3rd) + _Pustakam_ (1st) + _Pathyate_ (verb matches Pustakam).
        
- मया पत्रं लिख्यते। (A letter is written by me.)
    
    - _Maya_ (3rd) + _Patram_ (1st) + _Likhyate_ (verb matches Patram).
        

## 3. Bhava Vachya (भाववाच्य) - Impersonal Voice

Bhava Vachya is used when the verb is intransitive (has **no Object / Karma**). The focus is entirely on the action/feeling (Bhava).

- **Formula:** Subject (3rd Case) + No Object + Verb (Always Fixed)
    
- **Karta (Subject):** Tritiya Vibhakti (3rd Case)
    
- **Karma (Object):** None (X)
    
- **Kriya (Verb):** ALWAYS fixed in **Pratham Purush, Ekavachan** (यते), regardless of the subject's number or person.
    

**Examples:**

- बालकेन हस्यते। (It is laughed by the boy.)
    
- मया सुप्यते। (It is slept by me.)
    
- तैः क्रीड्यते। (It is played by them.) _Notice the verb stays 'kridyate' even though the subject is plural._
    

## 🔄 Vachya Parivartan (Conversion Rules)

### Rule 1: Subject Conversion (1st Case ↔ 3rd Case)

To change from Kartri to Karma/Bhava (or vice versa), you must memorize how common pronouns and nouns change between Prathama (1st) and Tritiya (3rd) Vibhakti.

|   |   |   |
|---|---|---|
|**Word Type**|**Prathama (Kartri Vachya)**|**Tritiya (Karma/Bhava Vachya)**|
|**I (अस्मद्)**|अहम् (Aham)|मया (Maya)|
|**We two**|आवाम् (Aavam)|आवाभ्याम् (Aavabhyam)|
|**We all**|वयम् (Vayam)|अस्माभिः (Asmabhih)|
|**You (युष्मद्)**|त्वम् (Twam)|त्वया (Twaya)|
|**You all**|यूयम् (Yuyam)|युष्माभिः (Yushmabhih)|
|**He (तत् - M)**|सः (Sah)|तेन (Tena)|
|**She (तत् - F)**|सा (Saa)|तया (Tayaa)|
|**Who (किम् - M)**|कः (Kah)|केन (Kena)|
|**Boy (Nouns)**|बालकः / रामः (Balakah/Ramah)|बालकेन / रामेण (Balakena/Ramena)|
|**Girl (Nouns)**|बालिका / लता (Balika/Lata)|बालिकया / लतया (Balikaya/Lataya)|

### Rule 2: Object Conversion (2nd Case ↔ 1st Case)

- Often, neuter words (like _Phalam_, _Pustakam_, _Patram_) look exactly the same in both 1st and 2nd cases, so they don't seem to change spelling, but grammatically they do.
    
- Masculine objects change noticeably: ग्रन्थम् (2nd) ➔ ग्रन्थः (1st).
    

### Rule 3: Verb Conversion (Atmanepada + य)

To make a passive verb, take the original root (Dhatu), add 'य' (ya), and then add Atmanepada suffixes (ते, इते, अन्ते).

|   |   |   |
|---|---|---|
|**Root (Dhatu)**|**Kartri Vachya (Active)**|**Karma/Bhava Vachya (Passive)**|
|पठ् (Read)|पठति (Pathati)|पठ्यते (Pathyate)|
|गम् (Go)|गच्छति (Gacchati)|गम्यते (Gamyate) - _Note: uses original root_|
|लिख् (Write)|लिखति (Likhati)|लिख्यते (Likhyate)|
|दृश् (See)|पश्यति (Pashyati)|दृश्यते (Drishyate) - _Note: uses original root_|
|पा (Drink)|पिबति (Pibati)|पीयते (Piyate) - _Special rule: 'पा' becomes 'पी'_|
|दा (Give)|ददाति (Dadati)|दीयते (Diyate) - _Special rule: 'दा' becomes 'दी'_|
|कृ (Do)|करोति (Karoti)|क्रियते (Kriyate)|

## 🎯 Quick Check Formulas for Exam MCQs

1. **If Subject has 3rd Case (e.g., मया, रामेण) ➔** Look for a verb ending in **-यते, -येते, -यन्ते**.
    
2. **If Verb ends in -यते (e.g., पठ्यते) ➔** The Subject MUST be in the **3rd Case (Tritiya)**.
    
3. **If Subject is 1st Case (e.g., अहम्, सः) ➔** Verb MUST be normal active voice (e.g., **-ति, -ामि**).
    
4. **If there is NO Object ➔** It is Bhava Vachya, Verb is ALWAYS **-यते** (Singular).
