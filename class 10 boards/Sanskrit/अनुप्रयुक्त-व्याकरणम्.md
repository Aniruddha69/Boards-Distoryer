

# ⚙️ Applied Grammar (अनुप्रयुक्त-व्याकरणम्)

This section outlines the specific grammatical concepts to be studied.

# Inside of Syllabus

|              **Grammar Topic**              | **Sub-topics / Details Covered**                                                                        |
| :-----------------------------------------: | ------------------------------------------------------------------------------------------------------- |
|           **[[सन्धिः]] (Sandhi)**           | Swara Sandhi, Vyanjana Sandhi, Visarga Sandhi                                                           |
|           **[[समासः]] (Samasa)**            | Tatpurusha, Dvandva, Avyayibhava, Bahuvrihi                                                             |
|    **[[प्रत्ययाः]] (Pratyaya/Suffixes)**    | Krit (Tva, Tumun, Lyap), Taddhita (Matup, Thak, Tal, Tva), Stri (Top)                                   |
|   **[[वाच्य-परिवर्तनम्]] (Voice Change)**   | Active and Passive voice transformations (Lat Lakar / Present Tense only)                               |
|     **[[समय-लेखनम्]] (Time / Ghatika)**     | Full hour, Sapad (quarter past), Sardh (half past), Padon (quarter to)                                  |
|     **[[अव्ययपदानि]] (Indeclinables)**      | Application and usage of non-changing words in sentences                                                |
| **[[अशुद्धि-संशोधनम्]] (Error Correction)** | Correcting sentence errors based on gender (Linga), number (Vachan), case (Vibhakti), and tense (Lakar) |
