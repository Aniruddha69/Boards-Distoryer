# 📝 Sanskrit Grammar Notes: Sandhi (Class 10 Manika)

**Sandhi (सन्धि)** is the phonetic combination or blending of two sounds (letters) when they come close to each other. 
Formula: `First Word (Last Letter) + Second Word (First Letter) = Sandhi`

---

## 1. Vyanjana Sandhi (व्यञ्जन सन्धि)
Occurs when a consonant combines with a vowel or another consonant.

### A. Jashatva Sandhi (जश्त्व सन्धि) - 1st to 3rd Letter Rule
When the **1st letter** of a Varga (क्, च्, ट्, त्, प्) is followed by a Vowel, the 3rd, 4th, or 5th letter of a Varga, or an Antastha (य्, र्, ल्, व्, ह्), the 1st letter transforms into the **3rd letter** of its own Varga.

*   **क्** changes to **ग्**
*   **च्** changes to **ज्**
*   **ट्** changes to **ड्**
*   **त्** changes to **द्**
*   **प्** changes to **ब्**

| Word 1 (Ends with 1st) | Word 2 (Starts with...) | Sandhi Word |
| :--- | :--- | :--- |
| वाक् (k) | ईशः (Vowel) | **वागीशः** (g) |
| अच् (ch) | अन्तः (Vowel) | **अजन्तः** (j) |
| जगत् (t) | ईशः (Vowel) | **जगदीशः** (d) |
| दिक् (k) | गजः (3rd letter) | **दिग्गजः** (g) |

### B. Anunasika Sandhi (अनुनासिक सन्धि) - 1st to 5th Letter Rule
When the **1st letter** of a Varga (क्, च्, ट्, त्, प्) is followed by a **5th letter** (usually न् or म्), the 1st letter transforms into the **5th letter** of its own Varga.

*   **क्** changes to **ङ्**
*   **ट्** changes to **ण्**
*   **त्** changes to **न्**

| Word 1 (Ends with 1st) | Word 2 (Starts with 5th) | Sandhi Word |
| :--- | :--- | :--- |
| वाक् (k) | मयम् (m) | **वाङ्मयम्** (ng) |
| षट् (t) | मासः (m) | **षण्मासः** (n) |
| जगत् (t) | नाथः (n) | **जगन्नाथः** (n) |
| तत् (t) | न (n) | **तन्न** (n) |

### C. Anusvara Sandhi (अनुस्वार सन्धि) - The 'M' Rule
If a word ends in **म् (m)** and the next word starts with **ANY Consonant**, the **म्** changes to an Anusvara **( ं )** above the previous letter. *(Note: If the next word starts with a Vowel, the म् simply joins the vowel).*

| Word 1 (Ends with म्) | Word 2 (Starts with) | Sandhi Word | Reason |
| :--- | :--- | :--- | :--- |
| हरिम् | वन्दे | **हरिं वन्दे** | Next is a consonant (व) |
| सत्यम् | वद | **सत्यं वद** | Next is a consonant (व) |
| अहम् | गच्छामि | **अहं गच्छामि** | Next is a consonant (ग) |
| अहम् | आगतः | **अहमागतः** | Next is a vowel (आ) - NO Sandhi change |

## 2. Visarga Sandhi (विसर्ग सन्धि)
Occurs when a Visarga `(:)` combines with a vowel or a consonant.

### A. Utva Sandhi (उत्व सन्धि) - Visarga to 'O'
**Rule 1 (Avagraha):** If `अ` comes before the Visarga, and `अ` comes immediately after it, the Visarga changes to **ओ (o)** and the following `अ` becomes an Avagraha **(ऽ)**.
*   सः + अपि = **सोऽपि**
*   रामः + अयम् = **रामोऽयम्**

**Rule 2 (Soft Consonant):** If `अ` comes before the Visarga, and it is followed by a 3rd, 4th, 5th letter, or य्, र्, ल्, व्, ह्, the Visarga changes to **ओ (o)**.
*   मनः + रथः = **मनोरथः**
*   नमः + नमः = **नमो नमः**
*   रामः + गच्छति = **रामो गच्छति**

### B. Rutva Sandhi (रुत्व सन्धि) - Visarga to 'R' (र्)
If the Visarga is preceded by **ANY vowel EXCEPT अ/आ**, and followed by a Vowel, a 3rd/4th/5th letter, or य्, र्, ल्, व्, ह्, the Visarga changes to a half 'r' **(र्)**.

| Word 1 (Visarga) | Word 2 | Sandhi Word |
| :--- | :--- | :--- |
| मुनिः (i) | अयम् | **मुनिरयम्** |
| भानुः (u) | उदेति | **भानुरुदेति** |
| पितुः (u) | इच्छा | **पितुरिच्छा** |
| गुरुः (u) | गच्छति | **गुरुर्गच्छति** |

### C. Satva Sandhi (सत्व सन्धि) - The S/Sh/Sh Rules
Visarga transforms into a sibilant based on the starting consonant of the next word.

1.  **Visarga + च / छ = श् (Sh)**
    *   रामः + च = **रामश्च**
    *   कः + चित् = **कश्चित्**
2.  **Visarga + ट / ठ = ष् (Sh - Retroflex)**
    *   धनुः + टङ्कारः = **धनुष्टङ्कारः**
3.  **Visarga + त / थ = स् (S)**
    *   नमः + ते = **नमस्ते**
    *   इतः + ततः = **इतस्ततः**

### D. Visarga Lopa (विसर्ग लोप) - Deletion of Visarga
Sometimes the Visarga simply drops out.
**Rule 1 (With Sah/Eshah):** The words **सः (He)** and **एषः (This)** lose their Visarga if followed by ANY letter EXCEPT 'अ'.
*   सः + गच्छति = **स गच्छति**
*   एषः + बालः = **एष बालः**

**Rule 2 (Preceded by Aa):** If the Visarga is preceded by `आ` and followed by any Vowel or Soft Consonant (3rd, 4th, 5th, y, r, l, v, h).
*   बालाः + अत्र = **बाला अत्र**
*   छात्राः + गच्छन्ति = **छात्रा गच्छन्ति**

## 3. Swar Sandhi (स्वर सन्धि) - Vowel Sandhi
*Mandatory for Class 10 Manika Syllabus.* Occurs when a vowel combines with another vowel.

### A. Dirgha Sandhi (दीर्घ सन्धि) - The Long Vowel Rule
When two similar vowels (short or long) meet, they combine to form their **long (दीर्घ)** version.
*   **अ / आ + अ / आ = आ** (e.g., पुस्तक + आलयः = पुस्तकालयः)
*   **इ / ई + इ / ई = ई** (e.g., मुनि + ईशः = मुनीशः)
*   **उ / ऊ + उ / ऊ = ऊ** (e.g., भानु + उदयः = भानूदयः)

### B. Guna Sandhi (गुण सन्धि)
When **अ / आ** is followed by a different vowel, they blend into a new sound.
*   **अ/आ + इ/ई = ए (e)** (e.g., नर + ईशः = नरेशः)
*   **अ/आ + उ/ऊ = ओ (o)** (e.g., महा + उत्सवः = महोत्सवः)
*   **अ/आ + ऋ = अर् (ar)** (e.g., महा + ऋषिः = महर्षिः)

### C. Vriddhi Sandhi (वृद्धि सन्धि) - The "Double Matra" Rule
When **अ / आ** is followed by ए/ऐ or ओ/औ, they "grow" (Vriddhi) into the strongest version of that sound.
*   **अ/आ + ए/ऐ = ऐ (ai)** (e.g., एक + एकम् = एकैकम्)
*   **अ/आ + ओ/औ = औ (au)** (e.g., महा + ओषधिः = महौषधिः)

### D. Yan Sandhi (यण् सन्धि) - Vowel to Consonant
When **इ, उ, ऋ** are followed by any *different* vowel, they turn into half-consonants.
*   **इ/ई** changes to **य् (y)** (e.g., यदि + अपि = यद्यपि)
*   **उ/ऊ** changes to **व् (v)** (e.g., सु + आगतम् = स्वागतम्)
*   **ऋ** changes to **र् (r)** (e.g., पितृ + आदेशः = पित्रादेशः)

### E. Ayadi Sandhi (अयादि सन्धि)
When **ए, ऐ, ओ, औ** are followed by any vowel, they break apart into new sounds.
*   **ए** changes to **अय् (ay)** (e.g., ने + अनम् = नयनम्)
*   **ऐ** changes to **आय् (aay)** (e.g., नै + अकः = नायकः)
*   **ओ** changes to **अव् (av)** (e.g., पो + अनः = पवनः)
*   **औ** changes to **आव् (aav)** (e.g., पौ + अकः = पावकः)
