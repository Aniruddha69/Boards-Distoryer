# Ghatika (Samay Lekhanam) Notes

💡 **Exam Tip:** Ghatika (Time Writing) is a highly scoring **4-marks topic** in the CBSE Class 10 Sanskrit board exams. It has a very limited set of rules, making it easy to score full marks with a little practice!

## Basic Vocabulary

To tell the time in Sanskrit, you must know the numbers from 1 to 12. Notice the slight changes in spelling for time (e.g., _Chatur_ becomes _Chatuh/Chatur_, _Shash_ becomes _Shad_).

- **1** - Eka (एक)
- **2** - Dvi (द्वि)
- **3** - Tri (त्रि)
- **4** - Chatur (चतुर्)
- **5** - Pancha (पञ्च)
- **6** - Shad (षड्)
- **7** - Sapta (सप्त)
- **8** - Ashta (अष्ट)  
- **9** - Nava (नव)
- **10** - Dasha (दश)   
- **11** - Ekadasha (एकादश)
- **12** - Dvadasha (द्वादश)   

## 1. Full Hours (पूर्ण समय) - Vadanam (वादनम्)

When the minute hand is at 12 (00 minutes), we simply attach **Vadanam** (वादनम्) to the number.

|                    |                |
|:------------------:|:--------------:|
| **Time (Digital)** | **Devanagari** |
|        1:00        |    एकवादनम्    |
|        2:00        |   द्विवादनम्   |
|        3:00        |   त्रिवादनम्   |
|        4:00        |  चतुर्वादनम्   |
|        5:00        |   पञ्चवादनम्   |
|        6:00        |   षड्वादनम्    |
|        7:00        |   सप्तवादनम्   |
|        8:00        |   अष्टवादनम्   |
|        9:00        |    नववादनम्    |
|       10:00        |    दशवादनम्    |
|       11:00        |  एकादशवादनम्   |
|       12:00        |  द्वादशवादनम्  |

## 2. Quarter Past (सपाद) - Sapada (15 minutes)

When the time is 15 minutes past the hour, use the prefix **Sapada** (सपाद). _Sapada_ literally means "with a quarter" (Sa + Pada).

- **Formula:** Sapada + Number + Vadanam   

|          |                              |
|:--------:|:----------------------------:|
| **Time** |        **Devanagari**        |
|   1:15   | सपादैकवादनम् / सपाद-एकवादनम् |
|   4:15   |       सपाद-चतुर्वादनम्       |
|   9:15   |        सपाद-नववादनम्         |

## 3. Half Past (सार्ध) - Sardha (30 minutes)

When the time is 30 minutes past the hour, use the prefix **Sardha** (सार्ध). _Sardha_ means "with a half" (Sa + Ardha).

- **Formula:** Sardha + Number + Vadanam

|          |                  |
| :------: | :--------------: |
| **Time** |  **Devanagari**  |
|   2:30   | सार्ध-द्विवादनम् |
|   5:30   | सार्ध-पञ्चवादनम् |
|  10:30   |  सार्ध-दशवादनम्  |

## 4. Quarter To (पादोन) - Padona (45 minutes) - ⚠️ CRITICAL RULE

When the time is 45 minutes past the hour (quarter to the next hour), use the prefix **Padona** (पादोन). _Padona_ means "less by a quarter" (Pada + Una).

🚨 **IMPORTANT RULE:** When using Padona, you **MUST USE THE NEXT HOUR**, not the current hour written in digits. Just like in English, 3:45 is "quarter to **four**", in Sanskrit it is "Padona **Chatur**-vadanam".

- **Formula:** Padona + **Next Number** + Vadanam  

|           |                    |
|:---------:|:------------------:|
| **Time**  |   **Devanagari**   |
| **3:45**  | पादोन-चतुर्वादनम्  |
| **7:45**  |  पादोन-अष्टवादनम्  |
| **11:45** | पादोन-द्वादशवादनम् |
| **12:45** |   पादोन-एकवादनम्   |

## 5. 'Vadanam' (वादनम्) vs 'Vadane' (वादने)

Students often get confused between when to write _Vadanam_ and when to write _Vadane_. The rule is simple based on grammar cases.

### Vadanam (वादनम्) - Standalone Time

Use **Vadanam** when you are simply stating what the time is right now. It is the nominative case.

- **Question:** What is the time? (कः समयः?)
- **Answer:** It is 5 o'clock.
- **Sanskrit:** पञ्च**वादनम्**। (Pancha-**vadanam**)

### Vadane (वादने) - Time in a Sentence (Locative Case)

Use **Vadane** when describing **at what time** an action takes place. It acts as the locative case (Saptami Vibhakti) representing "at". If there is a blank in a sentence describing an action, always use _Vadane_.

- **Question:** At what time do you wake up? (भवान् कति वादने उत्तिष्ठति?)    
- **Answer:** I wake up **at** 5 o'clock.
- **Sanskrit:** अहम् पञ्च**वादने** उत्तिष्ठामि। (Aham pancha-**vadane** utthishthami.)

**More Examples of 'Vadane':**

- Ram goes to school at 7:30. -> रामः सार्ध-सप्त**वादने** विद्यालयं गच्छति। (Rama sardha-sapta**vadane** vidyalayam gacchati.)
- The train arrives at 10:15. -> रेलयानम् सपाद-दश**वादने** आगच्छति। (Relayanam sapada-dasha**vadane** aagacchati.)
