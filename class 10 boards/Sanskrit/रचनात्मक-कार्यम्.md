# ✍️ Writing Skills (रचनात्मक-कार्यम्)

This section covers the composition and translation topics.

|                                              |                                                                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Writing Skill**                            | **Description**                                                                                               |
| **[[पत्र-लेखनम्]] (Letter Writing)**         | Formal or informal letter completion using a fill-in-the-blank format with a clue box (_Manjusha_).           |
| **[[चित्र-वर्णनम्]] (Picture Composition)**  | Framing basic Sanskrit sentences describing a provided visual image.                                          |
| **[[अनुच्छेद-लेखनम्]] (Paragraph Writing)**  | Writing a short paragraph on a specific topic using provided vocabulary (alternative to picture composition). |
| **[[संवाद]] / कथा-पूर्तिः (Dialogue/Story)** | Completing a conversational dialogue or a short story using a word box.                                       |
| **[[अनुवादः]] (Translation)**                | Translating simple sentences from Hindi or English into Sanskrit.                                             |
