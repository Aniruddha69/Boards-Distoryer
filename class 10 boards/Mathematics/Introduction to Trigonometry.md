# Class 10 Mathematics: Introduction to Trigonometry (Complete Guide & PYQ Bank)

## 1. Trigonometric Ratios ($P, B, H$ System)

In a right-angled triangle, with respect to reference acute angle $\theta$:

- $P$ = Perpendicular (Side opposite to angle $\theta$)
    
- $B$ = Base (Side adjacent to angle $\theta$)
    
- $H$ = Hypotenuse (Longest side, opposite to $90^\circ$)
    

By Pythagoras theorem:  

$$H^2 = P^2 + B^2 \implies H = \sqrt{P^2 + B^2}$$

### Fundamental Ratios

$$\sin\theta = \frac{P}{H} \qquad\qquad \csc\theta = \frac{1}{\sin\theta} = \frac{H}{P}$$$$\cos\theta = \frac{B}{H} \qquad\qquad \sec\theta = \frac{1}{\cos\theta} = \frac{H}{B}$$$$\tan\theta = \frac{P}{B} \qquad\qquad \cot\theta = \frac{1}{\tan\theta} = \frac{B}{P}$$

### Quotient Relations

$$\tan\theta = \frac{\sin\theta}{\cos\theta}, \qquad \cot\theta = \frac{\cos\theta}{\sin\theta}$$

## 2. Fundamental Trigonometric Identities

### Primary Identities & Derived Forms

1. **Identity 1:**  
    
    $$\sin^2\theta + \cos^2\theta = 1$$
    - $\sin^2\theta = 1 - \cos^2\theta \implies \sin\theta = \sqrt{1 - \cos^2\theta}$  
        
    - $\cos^2\theta = 1 - \sin^2\theta \implies \cos\theta = \sqrt{1 - \sin^2\theta}$  
        
2. **Identity 2:**  
    
    $$\sec^2\theta - \tan^2\theta = 1 \quad \iff \quad \sec^2\theta = 1 + \tan^2\theta$$
    - $\tan^2\theta = \sec^2\theta - 1$  
        
    - $(\sec\theta - \tan\theta)(\sec\theta + \tan\theta) = 1 \implies \sec\theta - \tan\theta = \frac{1}{\sec\theta + \tan\theta}$  
        
3. **Identity 3:**  
    
    $$\csc^2\theta - \cot^2\theta = 1 \quad \iff \quad \csc^2\theta = 1 + \cot^2\theta$$
    - $\cot^2\theta = \csc^2\theta - 1$  
        
    - $(\csc\theta - \cot\theta)(\csc\theta + \cot\theta) = 1 \implies \csc\theta - \cot\theta = \frac{1}{\csc\theta + \cot\theta}$

## 4. CBSE Previous Year Questions (Grouped in Pairs: Easiest to Hardest)

### Type 1: Basic Triangle Evaluation ($P/B/H$)

#### Question 1.1 (CBSE 2019)

If $\sin\theta = \frac{3}{5}$, find the value of $\frac{\tan\theta + \cos\theta}{\cot\theta}$.

- **Solution:**
    
    1. $\sin\theta = \frac{P}{H} = \frac{3}{5} \implies P = 3k, H = 5k$.
        
    2. $B = \sqrt{H^2 - P^2} = \sqrt{(5k)^2 - (3k)^2} = \sqrt{16k^2} = 4k$.
        
    3. $\cos\theta = \frac{B}{H} = \frac{4}{5}$, $\tan\theta = \frac{P}{B} = \frac{3}{4}$, $\cot\theta = \frac{4}{3}$.
        
    4. Evaluate:  
        
        $$\frac{\frac{3}{4} + \frac{4}{5}}{\frac{4}{3}} = \frac{\frac{15 + 16}{20}}{\frac{4}{3}} = \frac{31}{20} \times \frac{3}{4} = \frac{93}{80}$$

#### Question 1.2 (CBSE 2021)

If $4\tan\theta = 3$, evaluate $\frac{4\sin\theta - \cos\theta}{4\sin\theta + \cos\theta}$.

- **Solution:**
    
    1. $4\tan\theta = 3 \implies \tan\theta = \frac{3}{4}$.
        
    2. Divide numerator and denominator by $\cos\theta$:  
        
        $$\frac{\frac{4\sin\theta}{\cos\theta} - \frac{\cos\theta}{\cos\theta}}{\frac{4\sin\theta}{\cos\theta} + \frac{\cos\theta}{\cos\theta}} = \frac{4\tan\theta - 1}{4\tan\theta + 1}$$
    3. Substitute $4\tan\theta = 3$:  
        
        $$\frac{3 - 1}{3 + 1} = \frac{2}{4} = \frac{1}{2}$$

### Type 2: Table Value Substitution & Linear Systems

#### Question 2.1 (CBSE 2020)

Evaluate:  

$$\frac{5\cos^2 60^\circ + 4\sec^2 30^\circ - \tan^2 45^\circ}{\sin^2 30^\circ + \cos^2 30^\circ}$$

- **Solution:**
    
    1. Denominator: $\sin^2 30^\circ + \cos^2 30^\circ = 1$.
        
    2. Substitute numerator values:  
        
        $$5\left(\frac{1}{2}\right)^2 + 4\left(\frac{2}{\sqrt{3}}\right)^2 - (1)^2 = 5\left(\frac{1}{4}\right) + 4\left(\frac{4}{3}\right) - 1$$$$= \frac{5}{4} + \frac{16}{3} - 1 = \frac{15 + 64 - 12}{12} = \frac{67}{12}$$

#### Question 2.2 (CBSE 2018, 2023)

If $\sin(A - B) = \frac{1}{2}$ and $\cos(A + B) = \frac{1}{2}$, where $0^\circ < A + B \le 90^\circ$ and $A > B$, find $A$ and $B$.

- **Solution:**
    
    1. $\sin(A - B) = \frac{1}{2} \implies A - B = 30^\circ \quad \text{--- (1)}$  
        
    2. $\cos(A + B) = \frac{1}{2} \implies A + B = 60^\circ \quad \text{--- (2)}$  
        
    3. Adding (1) and (2):  
        
        $$2A = 90^\circ \implies A = 45^\circ$$
    4. Subtracting (1) from (2):  
        
        $$2B = 30^\circ \implies B = 15^\circ$$

### Type 3: Reciprocal Sum Conjugate Questions ($(\sec\theta \pm \tan\theta)$ / $(\csc\theta \pm \cot\theta)$)

#### Question 3.1 (CBSE 2016, 2020)

If $\sec\theta + \tan\theta = p$, show that $\frac{p^2 - 1}{p^2 + 1} = \sin\theta$.

- **Solution:**
    
    1. Given $\sec\theta + \tan\theta = p \implies \sec\theta - \tan\theta = \frac{1}{p}$.
        
    2. Adding gives: $2\sec\theta = p + \frac{1}{p} = \frac{p^2 + 1}{p} \implies \sec\theta = \frac{p^2 + 1}{2p}$.
        
    3. Subtracting gives: $2\tan\theta = p - \frac{1}{p} = \frac{p^2 - 1}{p} \implies \tan\theta = \frac{p^2 - 1}{2p}$.
        
    4. Since $\sin\theta = \frac{\tan\theta}{\sec\theta}$:  
        
        $$\sin\theta = \frac{\frac{p^2 - 1}{2p}}{\frac{p^2 + 1}{2p}} = \frac{p^2 - 1}{p^2 + 1}$$
    
    - Hence Proved. $\blacksquare$  
        

#### Question 3.2 (CBSE 2022)

If $\csc\theta + \cot\theta = k$, find the value of $\cos\theta$ in terms of $k$.

- **Solution:**
    
    1. We know $\csc^2\theta - \cot^2\theta = 1 \implies \csc\theta - \cot\theta = \frac{1}{k}$.
        
    2. Add equations: $2\csc\theta = k + \frac{1}{k} = \frac{k^2 + 1}{k} \implies \csc\theta = \frac{k^2 + 1}{2k} \implies \sin\theta = \frac{2k}{k^2 + 1}$.
        
    3. Subtract equations: $2\cot\theta = k - \frac{1}{k} = \frac{k^2 - 1}{k} \implies \cot\theta = \frac{k^2 - 1}{2k}$.
        
    4. Since $\cos\theta = \cot\theta \times \sin\theta$:  
        
        $$\cos\theta = \left(\frac{k^2 - 1}{2k}\right) \times \left(\frac{2k}{k^2 + 1}\right) = \frac{k^2 - 1}{k^2 + 1}$$

### Type 4: Radical/Square-Root Rationalization Proofs

#### Question 4.1 (CBSE 2019, 2023)

Prove that:  

$$\sqrt{\frac{1 + \sin A}{1 - \sin A}} = \sec A + \tan A$$

- **Solution:**  
    
    $$\text{LHS} = \sqrt{\frac{(1 + \sin A)(1 + \sin A)}{(1 - \sin A)(1 + \sin A)}} = \sqrt{\frac{(1 + \sin A)^2}{1 - \sin^2 A}}$$
    
    Using $1 - \sin^2 A = \cos^2 A$:  
    
    $$\text{LHS} = \sqrt{\frac{(1 + \sin A)^2}{\cos^2 A}} = \frac{1 + \sin A}{\cos A} = \frac{1}{\cos A} + \frac{\sin A}{\cos A} = \sec A + \tan A = \text{RHS}$$
    - Hence Proved. $\blacksquare$  
        

#### Question 4.2 (CBSE 2020 Standard)

Prove that:  

$$\sqrt{\frac{\sec\theta - 1}{\sec\theta + 1}} + \sqrt{\frac{\sec\theta + 1}{\sec\theta - 1}} = 2\csc\theta$$

- **Solution:** Take LHS and make a common denominator:  
    
    $$\text{LHS} = \frac{(\sqrt{\sec\theta - 1})^2 + (\sqrt{\sec\theta + 1})^2}{\sqrt{(\sec\theta + 1)(\sec\theta - 1)}} = \frac{(\sec\theta - 1) + (\sec\theta + 1)}{\sqrt{\sec^2\theta - 1}}$$
    
    Using $\sec^2\theta - 1 = \tan^2\theta$:  
    
    $$\text{LHS} = \frac{2\sec\theta}{\sqrt{\tan^2\theta}} = \frac{2\sec\theta}{\tan\theta} = 2 \times \frac{\frac{1}{\cos\theta}}{\frac{\sin\theta}{\cos\theta}} = \frac{2}{\sin\theta} = 2\csc\theta = \text{RHS}$$
    - Hence Proved. $\blacksquare$  
        

### Type 5: High-Difficulty Board Questions (NCERT Exemplar / 5-Markers)

#### Question 5.1 (CBSE 2015, 2018, 2024 Standard)

Prove that:  

$$\frac{\tan\theta}{1 - \cot\theta} + \frac{\cot\theta}{1 - \tan\theta} = 1 + \sec\theta\csc\theta$$

- **Solution:**
    
    1. Express terms in $\sin\theta$ and $\cos\theta$:  
        
        $$\text{LHS} = \frac{\frac{\sin\theta}{\cos\theta}}{1 - \frac{\cos\theta}{\sin\theta}} + \frac{\frac{\cos\theta}{\sin\theta}}{1 - \frac{\sin\theta}{\cos\theta}} = \frac{\frac{\sin\theta}{\cos\theta}}{\frac{\sin\theta - \cos\theta}{\sin\theta}} + \frac{\frac{\cos\theta}{\sin\theta}}{\frac{\cos\theta - \sin\theta}{\cos\theta}}$$$$= \frac{\sin^2\theta}{\cos\theta(\sin\theta - \cos\theta)} - \frac{\cos^2\theta}{\sin\theta(\sin\theta - \cos\theta)}$$
    2. Take common denominator $\sin\theta\cos\theta(\sin\theta - \cos\theta)$:  
        
        $$= \frac{\sin^3\theta - \cos^3\theta}{\sin\theta\cos\theta(\sin\theta - \cos\theta)}$$
    3. Factor using $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$:  
        
        $$= \frac{(\sin\theta - \cos\theta)(\sin^2\theta + \sin\theta\cos\theta + \cos^2\theta)}{\sin\theta\cos\theta(\sin\theta - \cos\theta)}$$
    4. Simplify using $\sin^2\theta + \cos^2\theta = 1$:  
        
        $$= \frac{1 + \sin\theta\cos\theta}{\sin\theta\cos\theta} = \frac{1}{\sin\theta\cos\theta} + \frac{\sin\theta\cos\theta}{\sin\theta\cos\theta} = \csc\theta\sec\theta + 1 = \text{RHS}$$
    
    - Hence Proved. $\blacksquare$  
        

#### Question 5.2 (CBSE 2017, 2020 Standard)

Prove that:  

$$\frac{\cos A - \sin A + 1}{\cos A + \sin A - 1} = \csc A + \cot A \quad \text{(using the identity } \csc^2 A = 1 + \cot^2 A\text{)}$$

- **Solution:**
    
    1. Divide numerator and denominator by $\sin A$:  
        
        $$\text{LHS} = \frac{\frac{\cos A}{\sin A} - \frac{\sin A}{\sin A} + \frac{1}{\sin A}}{\frac{\cos A}{\sin A} + \frac{\sin A}{\sin A} - \frac{1}{\sin A}} = \frac{\cot A - 1 + \csc A}{\cot A + 1 - \csc A} = \frac{(\csc A + \cot A) - 1}{(\cot A - \csc A) + 1}$$
    2. Substitute $1 = \csc^2 A - \cot^2 A$ in the numerator only:  
        
        $$= \frac{(\csc A + \cot A) - (\csc^2 A - \cot^2 A)}{(\cot A - \csc A + 1)}$$
    3. Factor numerator: $(\csc^2 A - \cot^2 A) = (\csc A + \cot A)(\csc A - \cot A)$:  
        
        $$= \frac{(\csc A + \cot A)\left[1 - (\csc A - \cot A)\right]}{\cot A - \csc A + 1} = \frac{(\csc A + \cot A)(1 - \csc A + \cot A)}{(\cot A - \csc A + 1)}$$
    4. Cancel the identical factor $(1 - \csc A + \cot A)$:  
        
        $$= \csc A + \cot A = \text{RHS}$$
    
    - Hence Proved. $\blacksquare$
